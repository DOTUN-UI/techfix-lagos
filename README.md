# TechFix Lagos Website

A responsive multi-page website for TechFix Lagos, a fictional laptop and phone repair shop. Built as a web development assignment.

## Live Site
https://YOUR-SITE-NAME.netlify.app

## Pages
- **Home** (`index.html`): hero section, reasons to choose us, customer reviews
- **About** (`about.html`): company story, mission and team
- **Services** (`services.html`): six repair services with a category filter
- **Contact** (`contact.html`): contact details and a validated contact form

## Features
- Semantic HTML5 structure
- External stylesheet (`style.css`) using CSS Flexbox and CSS Grid
- Responsive design with media queries for phone, tablet and desktop
- External JavaScript (`script.js`) with:
  - a mobile menu toggle
  - a services filter (All, Laptops, Phones)
  - contact form validation with error and success messages

## Note on the contact form
This is a demo form. It validates the user's input but does not send messages anywhere, because no backend is connected.

## Technologies Used
HTML5, CSS3, JavaScript, GitHub, Netlify
